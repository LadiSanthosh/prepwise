# Problem

Candidates struggle to prepare for technical interviews.

Most platforms provide static questions and lack
personalized feedback.

# Solution

Create an AI interviewer that conducts realistic
mock interviews.

The AI should:

- Ask questions
- Analyze answers
- Ask follow-up questions
- Generate feedback

# Target Users

- Freshers
- Software Developers
- Job seekers
- Students

# MVP Goal

Allow users to practice technical interviews
without requiring login.
